# Semantic HTML5 Layout Structure

A clean web page layout created strictly using modern semantic HTML5 tags and CSS Flexbox to mirror a wireframe design.

## Technical Details
-  Header: Main site header section.
-  Navigation: Menu bar container.
-  Main Content Area: Flexbox wrapper for page content.
-  Section & Article: Primary and secondary content blocks.
-  Aside: Sidebar container.
-  Footer: Page footer section.

## Getting Started
Open index.html in any browser or run with VS Code Live Server.
